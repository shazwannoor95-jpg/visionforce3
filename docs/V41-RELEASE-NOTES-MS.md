# VISIONFORGE 3 v0.0.0.1

Asas versi automatik, checkpoint, projek SQLite, backup/restore salinan, Electron + React, registry 18 skill, simpanan key melalui penyulitan OS dan adapter worker PDF ke MP4. Semua commit tugasan ini berkongsi versi sama.

Versi ini DRAFT sehingga bukti Windows native dan ujian penerimaan selesai. Binary tanpa sijil code-signing ialah UNSIGNED. Pengedaran komersial tertakluk lesen Remotion, FFmpeg dan aset pihak ketiga.

Tiada Google AI Studio TTS/browser provider production, inferens LLM atau GPU berbayar diaktifkan. Cloud memerlukan worker yang dikonfigurasi; planner contoh menggunakan petikan tepat dokumen. Runtime/model Linux yang diuji dahulu tidak dibundel secara membuta tuli ke Windows.

Release stabil hanya diterbitkan melalui workflow manual yang diluluskan selepas build, smoke Windows, installer/uninstaller, portable, video dan checksums lulus. Artifak lama tidak ditimpa.
